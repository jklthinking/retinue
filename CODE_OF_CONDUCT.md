# Code of Conduct / 行为准则

RETINUE is a coordination tool. The people around it — operators, contributors,
and the agents they run — deserve a workspace that stays usable.

RETINUE 是一套协作工具。围着它工作的人——运营者、贡献者、以及他们运行的
agent——都值得一个还能继续共事的空间。

## Expected / 期望

- Be precise and assume good faith. Disagree with the work, not the person.
- Do not publish credentials, private task text, or someone else's data in an
  issue, pull request, or screenshot. Use synthetic examples.
- Do not treat an agent, a task card, or a chat message as an authority. Those
  are untrusted inputs; see [docs/security.md](docs/security.md).
- Give credit. Do not submit work you cannot license under the contributor
  terms in [CONTRIBUTING.md](CONTRIBUTING.md).

- 把话说清楚，并默认对方出于善意。针对工作本身争论，而不是针对人。
- 不要在 Issue、Pull Request 或截图里公开凭据、他人的任务正文或真实数据。
  用合成示例。
- 不要把 agent、任务卡或聊天消息当成指令来源。那些是不受信任的输入。
- 标明出处。不要提交你无法按 [CONTRIBUTING.md](CONTRIBUTING.md) 授权的内容。

## Unacceptable / 不可接受

Harassment, threats, doxxing, sustained personal attacks, and publishing
private information are not welcome. Neither is using this project to attack
systems you do not operate, or to smuggle executable instructions through
task text, receipts, or chat payloads.

骚扰、威胁、人肉、持续人身攻击、以及公开他人隐私，都不被接受。利用本项目
攻击你并未运营的系统，或通过任务正文、回执、聊天载荷夹带可执行指令，同样
不被接受。

## Enforcement / 执行

Maintainers may refuse, edit, or revert a contribution, and may limit
participation, when this standard is broken. Reports go through the private
channel named in [SECURITY.md](SECURITY.md). Do not open a public issue that
repeats the harmful material.

维护者可以拒绝、编辑或回退贡献，并在必要时限制参与。报告请走
[SECURITY.md](SECURITY.md) 中的私密渠道。不要开一张会把有害内容再公开一遍
的 Issue。
